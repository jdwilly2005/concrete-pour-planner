# Concrete Pour Planner

A single-file web app (index.html: plain HTML, CSS, JavaScript, no build tools). See spec.md for what the app does.

## Rules
- After each request, add an entry to prompts.md: what I asked, what you changed, and whether it worked.
- Update spec.md first whenever the app's behavior changes, then change the app to match.
- Save new files in the right folder (below). Don't create files at the top level other than the four listed.

## Layout
Top level (GitHub Pages needs index.html here):
- AGENTS.md - these instructions
- spec.md - the spec for the app
- prompts.md - prompt log
- index.html - the app

Numbered folders (each has a README.md):
- 00_planning/ - notes and sketches
- 01_data/ - data files (none used by this app)
- 02_validation/ - hand calculations and test cases
- 03_output/ - screenshots and exported results
